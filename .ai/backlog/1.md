# Epic: MVP ACP Server

## Summary

A usable-for-basic-use ACP v1 server: an agent host connects over stdio
(JSON-RPC 2.0), initializes with protocol version negotiation, runs
sessions with streaming text, backed by an OpenAI-compatible
Responses API (OpenAI or DeepSeek via `OPENAI_URL`). Env-only configuration —
no config file. Local dev deployment; cross-platform and CI releases deferred.

## Status

- **Priority:** P0
- **Progress:** 0%
- **Target:** none (no deadline)

## Features

### Feature: stdio JSON-RPC 2.0 transport (P0)
- **Use cases:** client sends requests/notifications on stdin; server responds on stdout; errors and `request_id` correlation
- **Requirements:** frame parse/serialize; request/response/notification/error objects; id-less notifications; batch handling if trivial
- **Dependencies:** none
- **Verification:** unit tests + round-trip fixtures (raw JSON → parsed → serialized)
- **Tasks:**
  - [x] `feature/stdio-jsonrpc-transport` — implement `protocol/json_rpc.zig` framing, `util/json.zig` helpers, stdin read loop in `main.zig` (done — merged 29893fd)

### Feature: initialize handshake + version negotiation (P0)
- **Use cases:** client negotiates protocol version and capabilities at startup
- **Requirements:** `initialize` handler per ACP v1 (`InitializeRequest` → `InitializeResponse`); `protocolVersion` (uint16) echoed/negotiated; capability surface honest to MVP; v2-ready dispatch seam
- **Dependencies:** F1
- **Verification:** captured client exchange transcript test; version mismatch behavior
- **Tasks:**
  - [x] `feature/initialize-handshake` — `initialize` method handler + version routing (done — merged 2326f45; registry in `protocol/v1/methods.zig`)

### Feature: session lifecycle + prompt flow (P0)
- **Use cases:** client creates a session, sends prompts, receives streamed progress
- **Requirements:** `session/new` (returns `sessionId`), `session/prompt` (prompt array of content blocks), `session/update` streaming notifications; `session/cancel` support; in-memory session store
- **Dependencies:** F1, F2
- **Verification:** scripted transcript tests (create → prompt → stream → response); cancel test
- **Tasks:**
  - [x] `feature/session-prompt-lifecycle` — session types + handlers + in-memory store (done — merged 6f2b588)

### Feature: OpenAI Responses provider adapter (P0)
- **Use cases:** turn text flows to the provider; deltas stream back as ACP updates
- **Requirements:** env config (`OPENAI_API_KEY`, `OPENAI_URL` default `https://api.openai.com/v1`, model — default `deepseek-chat` for DeepSeek usage); `util/http.zig` client; POST `/responses`; SSE parsing → `session/update` content chunks; provider error mapping to ACP errors
- **Dependencies:** F3
- **Verification:** mock SSE server tests; live smoke test with user's DeepSeek key (manual)
- **Tasks:**
  - [x] `feature/openai-responses-adapter` — `provider/adapter.zig` interface + `provider/openai.zig` Responses implementation (done — merged daa133a; worker-thread cancel)
