# Knowledge Base

This directory is the project's persistent memory — version-controlled, shared across all future agent sessions.

## Contents

| File | Purpose |
|------|---------|
| `glossary.md` | Project-specific terms, definitions, vernacular |
| `architecture.md` | System architecture decisions and rationale |
| `decisions.md` | Decision register — every decision with context, options, outcome |
| `bibliography.md` | External references — maps URLs to local files in `references/` |
| `samples/` | Example inputs, outputs, usage patterns (e.g., ACP transcripts) |
| `references/` | Saved copies of external docs (ACP spec, OpenAI API) |

## Conventions

- Before starting new work, check relevant files here first
- Record every decision in `decisions.md` (context, options considered, outcome)
- When a concept needs repeated explanation, add it to `glossary.md`
- When an architecture decision is revisited, update `architecture.md` with rationale
- Add new references to `bibliography.md` when saving to `references/`
